Project 03 · Psychometrics & Machine Learning

Detecting item parameter drift in large-scale assessments

A comparison of traditional IRT-based detection against machine learning (neural networks and XGBoost) for identifying item parameter drift, the phenomenon where a test item's behaviour changes between assessment cycles, threatening the fairness and comparability of large-scale assessments like PISA.

View full code and reproducible pipeline on GitHub →

BackgroundWhy this matters

When a test item stops measuring the same thing

Large-scale assessments, like PISA, are only meaningful if their items behave consistently across time and across groups of test-takers. When an item's statistical properties shift between assessment cycles, item parameter drift (IPD), comparisons across years become unreliable, even if no one changed the item's wording. Detecting this drift reliably matters for the validity of every trend reported from these assessments.

The traditional detection method, a Wald test built on item response theory (IRT), works well but has known limitations. Machine learning methods are increasingly proposed as an alternative or complement. This thesis tests that proposal directly, under conditions realistic enough to matter.

Research questionWhat I set out to answer

Can machine learning match traditional IRT-based detection?

Specifically: how do neural networks and XGBoost compare to the IRT-based Wald test in sensitivity, specificity, and robustness, across varying drift magnitude, drift proportion, drift type, and increasingly realistic and complex assessment structures, including multidimensionality and multi-country data?

MethodsSimulation design

99 simulated datasets, five levels of complexity

I simulated assessment data under progressively more realistic conditions, starting from a simple single-group Rasch model and building up to a multidimensional, multi-country 2PL design, closer to how an assessment like PISA actually operates.

Assessment design

  • 75 items: 15 anchor items shared across all booklets, 60 non-anchor items
  • 4 booklets, each with all anchor items plus 15 unique non-anchor items
  • Two assessment cycles (2015 and 2018), 2,000 respondents per country per cycle

ResultsWhat the data showed

Traditional IRT detection outperformed machine learning for subtle drift

Across every simulation condition, the IRT-based Wald test detected small drift (0.2 logits) more reliably than either machine learning method. All methods converged to near-perfect detection once drift became large (1.0 logits), the differences that mattered were concentrated entirely in the harder, more realistic cases.

Mean sensitivity for the simplest conditions (Simulations 1.1 and 1.2). At the smallest drift magnitude (0.2 logits), IRT detection (0.67 / 0.33) clearly outperforms the neural network (0.33 / 0.00) and XGBoost (0.19 / 0.00). All methods reach perfect sensitivity once drift reaches 0.5 logits or more.

The same pattern holds under more realistic, complex conditions (2PL model, multidimensionality, multiple countries), across all three drift types. IRT methods consistently lead at low drift magnitude; the gap narrows as drift magnitude increases.

A clearer view of the same result: IRT methods (green) sit consistently above the machine learning methods (blue, red) at low drift magnitude, across all three drift types, before the lines converge at magnitude 1.0.

What this means

Machine learning did not outperform the established method here, and that is itself a meaningful finding. By design, this points more toward a bottleneck effect, and the recommendation going forward is to implement ML at the parameter estimation stage rather than for correcting parameters afterward.

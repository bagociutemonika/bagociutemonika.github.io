# Monika Bagociuté — Portfolio

My personal research and UX portfolio, built as a static site and hosted on GitHub Pages.

**Live site:** [bagociutemonika.github.io](https://bagociutemonika.github.io)

## About

I'm a researcher working at the intersection of education, psychometrics, and UX, with a focus on turning rigorous analysis into clear, usable insight. This site showcases selected projects, including survey design and validation, item response theory and machine learning for assessment, and UX research for an independent product.

## Built with

Plain HTML, CSS, and inline SVG, no framework, no build step.
